# Planly — Responsive Product Pricing Cards

A responsive three-plan SaaS pricing section built with HTML, CSS and vanilla JavaScript.

## Features
- Three pricing plans: Starter, Pro and Business
- Monthly / Yearly billing switch updates every plan price and billing label
- Popular and Best Value ribbon badges
- Smooth card hover transforms and transitions
- Reduced-motion support with `prefers-reduced-motion`
- Responsive layouts for mobile (360px), tablet (768px) and desktop (1280px)
- Semantic buttons, keyboard support and visible focus styles
- Pricing values are stored in HTML `data-*` attributes

## Run locally
1. Extract the ZIP file.
2. Open the `Responsive_Product_Pricing_Cards` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

No installation or build step is required.

## Screenshots for submission
Capture the page twice:
1. Monthly view: keep the billing switch OFF.
2. Yearly view: click the billing switch ON.

Recommended screenshot sizes:
- Desktop: 1280px wide
- Mobile check: 360px wide

Save the screenshots as `monthly-view.png` and `yearly-view.png` in this folder before uploading your submission.

## Customize
- Edit plan prices in `index.html` using `data-monthly` and `data-yearly`.
- Edit colors, spacing and typography in `style.css`.
- Edit billing behavior in `script.js`.

## Note
This is a front-end demo. The CTA links use an example email address; replace `hello@example.com` with your own contact or signup destination before publishing.
