# Shakti Kourav — Personal Developer Portfolio

A responsive, single-page developer portfolio built with semantic HTML5, CSS Flexbox, CSS Grid and a small amount of vanilla JavaScript.

## Features
- Semantic `header`, `nav`, `main`, `section`, `article` and `footer` structure
- Responsive layouts for mobile (360px), tablet (768px) and desktop (1280px)
- CSS Grid for skills/projects and Flexbox for navigation, actions and content alignment
- Accessible mobile navigation with `aria-expanded` state
- Meaningful link labels, visible focus-friendly controls and reduced-motion support
- No framework or build step required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the VS Code Live Server extension.

## Publish for free with GitHub Pages
1. Create a public GitHub repository, for example `personal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and copy the live URL shown in the Pages section.
